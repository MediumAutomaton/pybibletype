___plugins/expansion
    Call a function in the module that returns an object that then you can work with.

    DESCRIPTION
    You're adding completely new functionality to BibleType! Good luck! We'll do what we can to help you.

    __init__(builder): Receive all the main menus that you can add options to. Also receive the writePrompter, so that you can add interruptions to the normal writing process. Also receive the settings plugin, so that you can add settings to the settings menu that will get saved to disk.

    (Right now, the builder wraps mainMenu, manageMenu, selectMenu, trackMenu, writePrompter, and settings.
    Maybe it should be an "API"; ex. it can call a method to get the current position.)

    Here's your API:

    addMainMenuItem(name, callback): Add an itme to the main menu

    addSelectMenuItem(name, data, callback): Add an item to the select menu, with default data if you want

    addTrackMenuItem(name, callback): Add something (usually a progress tracking display) to the tracker menu

    addManageMenuItem(name, callback): Add something to the manage menu

    open(): Access the open plugin, which you can use for things like accessing the writer for the currently selected project, or opening another project (the commentary plugin could do this, and keep its own writer without messing with the rest of the program's state at all)

    addWriterInterruption(callback): Register an interruption to the writing process. This lets another plugin take over between verses. A callback registered with this should take two arguments:
    - [dict] The position of the verse that the user just wrote
    - [bool] Whether this is the last verse in the chapter.

    The rest is up to you!



___plugins/menu
    DESCRIPTION
    The main menu system for BibleType.

    __init__(): Whatever you want to do. You'll get instantiated by the plugin manager.

    addMainMenuItem(name, callback): Add an item to the main menu

    addSelectMenuItem(name, data, callback): Add an item to the select menu, with default data if you want

    addTrackMenuItem(name, callback): Add something (usually a progress tracking display) to the tracker menu

    addManageMenuItem(name, callback): Add something to the manage menu

    presentMainMenu(): Called by the plugin manager once all the plugins are ready to go. This launches the menu that the user will interact with.

    This consolidated menu plugin supercedes all the smaller menu plugins below.



___plugins/menu/main
    DESCRIPTION
    The main menu displayed when BibleType is started. Provides options to launch various interfaces, both those included with BibleType by default and any additional ones that expansion plugins may register with this menu plugin.

    register(name, callback): Register a new menu item. The BibleType launcher will register the default items; you do not need to include any items in the main menu.
    Tip: If you're using MasterMenu, this should call straight through to addNumberedItem(name, callback=callback).

    prompt(): Present this menu to the user

    register(name, callback): Register a new menu item

    prompt(): Present this menu to the user

uniplugins/project/create/maketemplate:
    DESCRIPTION
    Make or modify a template file using information provided by prompttemplate or modifytemplate. (This plugin should never need to be replaced by a different one; preferably there would be one good, well-reviewed instance of this important code.)

    __init__(templateName): templateName is the name of the template file that this template maker will operate on.

    addBook(bookName, chapterList): chapterList is a list of the number of verses in each chapter. For example, suppose a book has 3 chapters, with 3, 5, and 7 verses respectively. chapterList would look like this: [3, 5, 7]. This method will add the book with the given name and chapters to the template being generated.

    updateChapter(bookName, chapterNumber, newNumVerses): Replace the number of verses in the given chapterNumber of the given bookName with newNumVerses

    commitTemplate(): We're done adding things to or modifying the template, so make sure that the template is saved to disk.



uniplugins/project/open:
    DESCRIPTION
    Look at a project file, determine what format it is, and return the correct kind of Writer with that project selected. The backend for the menu plugin's first built-in selectMenu item to let users choose a project.

    supportedFileExtensions(): Return a list of all file extensions supported across all the currently installed writer plugins. Perhaps useful if something wants to use an OS file picker; it can filter for BibleType project files.

    writerForProjectFile(fileName): Return an appropriate Writer for the given project file named fileName.

    currentWriter(): Return the Writer for the currently selected file (selected by the last call to writerForProjectFile()). If no file is currently selected, return None.



uniplugins/project/read:
    DESCRIPTION
    The distinction between project Reader and Writer only matters to the Prompter while the user is actually entering verses. If the user wants the current contents of the verse they're typing to be shown along with the prompt for that verse, the Prompter gets the existing verse from the Reader and saves the new verse to the project using the Writer. This is so that a Reader can pull a known correct verse from, say, an API, instead of from the saved project.

    - __init__(fileName): Called by the writer plugin that sets up the reader. The reader may or may not do anything with the provided filename.

    - verseContents(position): Get the contents of a certain verse



uniplugins/project/write:
    DESCRIPTION
    The project Writer actually both reads and writes the saved project. The underlying project format and the filesystem are abstracted through the Writer, allowing the rest of BibleType to operate on multiple different project formats.

    # General
    - __init__(fileName, selectMenu): Opens a project file and returns a Writer that implements the interface defined here and operates on that project file (or folder if it's a BT 3 format project). Or it can return False if it fails to load the project.
     Once the project has been loaded, register additional selection items with selectMenu. These are usually Book, Chapter, and Verse.

    - fileName(): Return the file name of the currently selected project

    - filePath(): Return the full file path of the currently selected project

    - pluginDataPath(): Return the full path of the plugin data folder (For BT 2 projects, this folder is created on-demand and sits next to the project. For BT 3 projects, this folder always exists and is contained within the overall project folder.)

    - @staticmethod supportedFileType(): Returns the file type that this Writer supports.
      If the Writer operates on a file, this can be a string of the file extension. ex. for BT 2, this returns ".json".
      If the Writer operates on a folder, this can be a dictionary:
      {
        "fileType": "folder",
        "folderContains": ["books", "project.json"]
      }
      The logic that sets up the Writer will use this information to perform a rudimentary evaluation of what projects are probably supported by this Writer.


    # Metadata
    - modifiedTime(): Returns the time, in seconds since the epoch, at which the project was last modified. If your format does not store this, return False.

    - lastPosition(): Returns the position of the verse that was last edited. If your format does not store this, return False.


    # Navigate
    - setPosition(position): Set the current working position

    - getPosition(position): Get the current working position

    - books(): Return the list of book names in the project

    - chaptersInBook(bookName): Return the number of chapters in the specified book

    - versesInChapter(bookName, chapterNumber): Return the number of verses in the specified chapter


    # Save
    - commitVerse(newVerseContents, advance=True): Replace the contents of the verse at the current working position. If advance is True, increment the current working position by 1 verse or, if this was the last verse in the chapter, commit the chapter.

    - commitChapter(advance=False): This method exists in service of BT's traditional practice of committing a verse to memory then committing the entire chapter to disk at once. If commitVerse() saves to disk, then this method may not need to do anything. But a Writer may choose to perform various housekeeping tasks here. If advance is True, set the position to the beginning of the next chapter or, if this was the last chapter in the book, commit the book.

    - commitBook(advance=False): This method exists to provide flexibility to Writers in terms of their housekeeping and how they save the project to disk. If commitVerse and/or commitChapter already save to disk, then you may not need to do anything with this method.

    - saveToDisk(): This method is called to ensure that the full project is saved to disk. Probably more useful for Writers like the BT 2 project writer, which hold the entire project in memory. The BT 3 writer only loads one chapter at a time, and the chapter is always saved to disk when commitChapter() is called, so the BT 3 writer does not do anything with this method.


    # Load
    - verseContents(position): Get the contents of the verse at the given position

    - reader(): Return an appropriate Reader for the loaded project
      (The Reader comes from the Writer because BT 3 projects, at least, can request multiple different kinds of Reader.)


    # Count
    - isVerseFilled(position): Return True if the verse at the given position has been given content by the user, and return False if the user has not populated that verse

    - chapterCount(bookName, chapterNumber): Return a dictionary:
    {
        "filled": int, the number of verses in the chapter that the user has populated
        "total": int, the total number of verses in the chapter
    }

    - bookCount(bookName): Return a dictionary:
    {
        "filled": int, the number of verses in the book that the user has populated
        "total": int, the total number of verses in the book
    }

    - projectCount(): Return a dictionary:
    {
        "filled": int, the number of verses in the project that the user has populated
        "total": int, the total number of verses in the project
    }



uniplugins/settings:
    DESCRIPTION
    Manages how settings are saved to and loaded from disk.

    __init__(): Initialization stuff. Probably load settings from disk.

    allSettings(): Return a dictionary of each setting and its value

    getSetting(setting): Get the value of a setting

    setSetting(setting, value): Set the value of a setting. Will raise WrongTypeError if the value is of the wrong type. Will raise NoSuchSettingError if that setting does not exist.

    addSetting(setting, default): Use this to add a new setting without overwriting the user-set value that might be there if the setting has been added and changed in previous runs of the program. And a user-set setting that is not added on this run (perhaps the plugin that added it was disabled) will not be accessible during this run.
