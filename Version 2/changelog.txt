1.0-0
- BibleType is a CP application with 4 commands:
  - btselect: select start point
  - btwrite: write, one verse at a time, from the selected start point
  - btcreate: create a new project (verses per chapter, chapters per book, book
    names)
  - bttrack: track progress with a list (showing verses completed in each
    chapter), bar graph by book, or bar graph bychapter

2.0-0
- New JSON project format
- WPM measurement

2.1-0
- Upgrade to MasterMenu 2.0
- Use os.replace() for more efficient backup
- bttrack can show percentages at the ends of the bars
- "!amend" support in btwrite, to easily re-do the previous verse

2.2-0
- Runs as a standalone command-line application
- Some things that used to be arguments to BibleType's separate commands are now
  settings, adjusted in a menu and saved to a file
- "Press Enter to continue..." after every unusual notification
- Can clear before displaying most menus (contextually-related menus are shown
  together); this is the new default but can be disabled in Settings

2.2-1
- Bargraph rendering split out to new 'bargraph' module; this new renderer has a couple extra features and fixes a bug
  - [bugfix] Always prints at exactly the correct width
  - Truncates book name if terminal is too narrow
  - More customizable; more easily allows for more settings in the future
- Split progress counting into new functions that all tracking displays now use; counting is now fast and consistent
  across all displays
- Split out the writing of a tracking display to either console or a file to a new helper function; this is now
  consistent across all displays and fixes some bugs found in the old implementations
- Remove now-unused import for 'math' module
- Fixed bug in track menu: exporting to a file once doesn't get you stuck exporting to files forever
- Consistency: there is now *always* a colon at the end of an input prompt (including prompting for verses!)
- Can actually change to the projects directory from the main directory instead of needing to run from the projects directory
- Fixed missing menu title at start check

2.3-0
- Can now set the start point through commandline arguments
- Always saves btsettings.json in the program directory, not the projects directory
- Can now hit Ctrl+C (KeyboardInterrupt) to restart the verse you're currently typing
- [bugfix] Trying to use the Track Progress menu when you don't have a project selected now pauses after the error message

2.3-1
- Now *actually* always saves btsettings.json in the program directory, not the projects directory
- Internal architectural improvements
- Change the --noreadline argument to the --readline argument, making *not* using readline the default behavior. This is
  because it was discovered that readline is not available on Windows.
- Percents are now shown at ends of bargraphs if you have that setting enabled
- Terminal width prompt now goes through the same askForNumber method as every other number prompt

[3.0-0]
- Companion project files for Notes and Commentaries; projects are now folders
  that can contain the main project and multiple such companion files
  - Example new option because of this: prompt for each commentary section after
    its verses, or all sections at end of chapter or book
- btread, to read back typed Scripture
- btmerge, to merge the completion progress of multiple projects
- Many more configuration settings, which are now persisted per project
  - Set them with btconfig
- New option in btselect's project selector for "New Project", which lists
  *templates* and lets the user select a *template* to start from
  - New template format
  - btcreate now creates *templates*
- More frequent saving in btcreate and ability to resume an interrupted btcreate
  sequence
  - Instead of the simple sequential prompting, use hierarchical menus! Like a book menu, which shows all the books so
  far, and the last two options are "Add Book" and "Remove Book", and the data for each item is how many chapters the
  book has, and when you go into a book, it shows a menu listing the chapters, with the same Add and Remove items at the
  end, and each item shows how many verses are in that chapter. And then you can select a chapter to modify how many
  verses it has. And then you can load up this menu on an existing project, so you can easily edit that project.
- btmodify, to modify existing templates
  - This includes adding / removing companions from the project folder
- The BibleType application now consists of multiple code files.
- Plugins can do things to the writing process (probably by registering functions to be run between verses and giving
  them some kind of access to info. like current book/chapter/verse)
- Launch with a plugin menu
  - Or start launcher with -d / --default option to use the defaults saved in a file
